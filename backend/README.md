# Maize Crop Stress Detection(Backend)

FastAPI backend for the Maize Crop Stress Detection system. Handles authentication, farm/sensor data, the check-in flow (leaf photo + sensor reading → severity + recommendation), alerts, feedback, and admin operations.


## Tech stack

- **Framework:** FastAPI, Python 3.11
- **Database:** PostgreSQL, SQLAlchemy 2.0 (async), Alembic migrations
- **Auth:** JWT (python-jose), bcrypt password hashing (passlib)
- **SMS:** Africa's Talking (sandbox during development)
- **Testing:** pytest, pytest-asyncio, httpx

## Setup

**1. Create and activate a virtual environment**
```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# Mac/Linux
source .venv/bin/activate
```

**2. Install dependencies**
```bash
pip install -r requirements.txt
```
> Note: SQLAlchemy's async support requires the `greenlet` package. This is covered by `sqlalchemy[asyncio]` in `requirements.txt` - if you hit `ModuleNotFoundError: No module named 'greenlet'`, run `pip install "sqlalchemy[asyncio]"` directly.

**3. Configure environment variables**
```bash
cp .env.example .env
```
Fill in `.env` with real values:
```
DATABASE_URL=postgresql+asyncpg://user:password@localhost:5432/dbname
SECRET_KEY=your-jwt-signing-secret
```
For quick local testing without a full Postgres setup, `DATABASE_URL=sqlite+aiosqlite:///./test.db` works as a temporary substitute - switch to real PostgreSQL before deployment.

**4. Run database migrations**
```bash
alembic upgrade head
```

**5. Run the app**
```bash
uvicorn app.main:app --reload
```
API docs (auto-generated by FastAPI) are available at `http://localhost:8000/docs`.
